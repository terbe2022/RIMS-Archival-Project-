## Vocabulary and image-context proposals

The current discussion proposes standard subject vocabularies plus archivist-defined local terms, potentially several vocabularies per accession. Research context can help source-grounded description and tagging; appraisal priorities remain separate from description prompts. Terminology matches are review signals, not automatic proof of value, and unexpected material must remain discoverable.

Image/event/person tags need supporting captions, source context or archivist confirmation. Do not infer a named identity from a face alone or infer an event’s significance from an unidentified gathering. These are proposed requirements to test, not features claimed complete.
