Archival Accession Processing Tool supports appraisal and description of born-digital archival collections. The workbench brings together accession context, file metadata, machine-generated suggestions and human review. Institutional owners decide policy, access, storage and release.

Current build: the original accession interface adapted for protected review of a four-accession, 2,375-record server export, including existing decisions. The export has no original document bodies or images. This password-protected test build is available online.

University Archivist Joanne Kaczmarek brought this tool to Tayler for archivists. Development is supported through Records and Information Management Services (RIMS).

The archival workflow

  1. Record accession context and appraisal criteria.
  2. Inventory files and route extraction and model work.
  3. Inspect descriptions, sensitivity flags and supporting evidence.
  4. Record human decisions and prepare an export for review.

Machine output does not authorize disposal or publication.
