# Data Management Plan - NSF DEB-1900417

- Types of data: specimen records (CSV/SQLite), floral and habitat quadrats (CSV), DNA barcodes (FASTA, BOLD submissions), photographs (JPEG/TIFF), GIS site layers (GeoJSON/shapefile), analysis code (R, Python).

- Standards: Darwin Core for specimen data; FGDC metadata for GIS layers.

- Access: data deposited in a public repository within one year of publication. Locations of federally listed species will be generalised to county; exact locations will be provided only to the state Natural Heritage Database.

- Preservation: university library repository for a minimum of ten years.
